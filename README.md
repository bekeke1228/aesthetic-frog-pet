# 审美吉蛙桌宠

一只常驻桌面的吉蛙：既能摸鱼陪伴，也能干点正事。

## 功能

- **陪伴**：待机 / 睡觉 / 点击反应 / 拖拽 / 庆祝 / 说话六种动画状态；随机躺平吐槽；空闲 90 秒自动睡觉。
- **番茄钟**：默认 25 分钟工作 + 5 分钟休息，可配置；完成时吉蛙庆祝 + 系统通知 + 提示音；统计当日番茄数。
- **待办清单**：添加、勾选完成、删除、清空已完成，本地持久化。
- **喝水 / 久坐提醒**：默认每 45 分钟 / 60 分钟提醒一次（吉蛙气泡 + 系统通知 + 提示音），可暂停。
- **和吉蛙对话**：点吉蛙窗口右上角 💬（或按 T），直接在桌面提问；面板「问吉蛙」同样可用。
- **天气查询**：问「上海天气」等会实时联网查当前气温和天气（Open-Meteo，无需 Key）。
- **AI 问答（可选）**：在面板设置填入 OpenAI API Key 并开启「AI 问答」后，吉蛙会用 AI 认真回答问题（本地蛙脑兜底；Key 明文保存在本地配置文件中）。
- **亲密度**：陪伴越久关系越好——陌生叫「人类」，满 2 小时改口「老大」，满 24 小时成为「挚友」。
- **托盘常驻**：显示/隐藏、番茄钟控制、提醒开关、打开面板、退出；支持开机自启。

## 运行

最简单的方式：双击项目根目录的 **`启动桌宠.bat`**。脚本会先关闭已在运行的旧版吉蛙，再启动最新版本，所以改完代码后直接双击即可，不用担心旧实例残留。

或者在命令行里：

```bash
pnpm install
pnpm start
```

首次安装需要联网下载 Electron。启动后吉蛙出现在桌面右下角。

## 分享给朋友

已打包好的**便携版**：`release/审美吉蛙桌宠-3.1.0-win.zip`（约 150MB）。
直接把 zip 发给朋友，解压后双击里面的 `审美吉蛙桌宠.exe` 就能运行，无需安装任何环境。

> 因为程序未做代码签名，朋友第一次运行时 Windows 可能弹出“已保护你的电脑”提示，
> 点「更多信息 → 仍要运行」即可。

想生成安装版（NSIS 安装向导），联网状态下执行 `pnpm run dist`；
本项目网络受限时 NSIS 下载会超时，可改用便携版分享。

## 操作

- 左键按住拖拽：移动吉蛙（位置会被记住）
- 单击：吉蛙吐槽
- 双击或右键：打开面板（番茄钟 / 待办 / 提醒 / 设置）
- 右键菜单与托盘菜单相同

## 素材结构

```text
assets/raw/          原始素材（你提供的图）
assets/sprites/      抠图后的透明精灵帧（自动生成，勿手改）
assets/manifest.json 帧表与播放速率（自动生成）
assets/contact_sheet.png 抠图检查图（可打开目检）
assets/sounds/       提示音（自动生成）
参考素材/            放你的 UI 示例图和气泡案例（供改进参考）
```

> 公开仓库不包含原始素材：`assets/raw/`、`参考素材/`、`release/` 已在本地保留但不会上传。
> 运行直接使用仓库内置精灵图；想换形象时，按命名规则自行放入 `assets/raw/` 后运行抠图脚本即可。

原始图命名规则：`<动作>_<序号>.png`，动作支持 `idle`、`sleep`、`click`、`drag`、`celebrate`、`talk`。

新增或替换素材后，重新运行：

```bash
pnpm exec node scripts/remove_background.py
```

（用 Python 运行：`python scripts/remove_background.py`）

## 数据位置

配置、待办、番茄统计和窗口位置保存在 Electron 用户数据目录的 `store.json`：
`C:\Users\<你>\AppData\Roaming\aesthetic-frog-pet\store.json`

## 常见问题

- **透明窗口不生效**：确认系统为 Windows 10/11，并开启桌面合成（Aero）。
- **双击没反应**：可能后台已有一个残留实例（占住了单实例锁）。打开任务管理器，结束所有 `electron.exe` 进程后再双击 `启动桌宠.bat`。
- **首次运行没有声音**：检查面板「设置 → 提示音」是否开启；若仍未播放，尝试把系统默认输出设备切换为扬声器。
- **想彻底移除**：托盘菜单 → 退出；若设置了开机自启，先在面板关闭。
